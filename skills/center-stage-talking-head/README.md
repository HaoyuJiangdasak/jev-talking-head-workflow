# center-stage-talking-head

Keep a recorded talking-head presenter as the visual anchor while semantic
cards, UI panels, metrics, steps, screenshots, labels, and callout lines appear
around the person. Use the Skill with `lead-media-edit` for rough cutting,
transcription, captions, audio cleanup, Remotion rendering, and final QA. The
Skill supports Codex and Claude Code user-level installation and keeps other
video Skills available.
