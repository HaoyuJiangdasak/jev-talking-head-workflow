# 居中人物 + 语义卡片参考片匹配档案

这是从用户提供的抖音参考片提炼出的可迁移视觉规则。它描述运动、版式和节奏，不复制原片的品牌、文案或截图。

## 画面骨架

- 人物是中央主叙事锚点，保留脸、嘴和手势；
- 左右两侧是信息卡安全区，顶部可放标题，底部给字幕留空；
- 需要完整解释 UI、手机或流程时，人物切到 `pip`，动效变成全屏舞台；
- 同一语义段落尽量保持同一舞台，只更新卡片内容和焦点，不把每句话切成独立页面。

## 语义触发

优先在这些位置换画面：

1. 新步骤：第一步、下一步、第二个问题；
2. 新对象：手机、录音、软件、报告、流程；
3. 数字或对比：增长、倍数、比例、时间；
4. 结论和警示：最重要、关键、注意、核查、事实。

普通连接词、态度句和重复强调不单独生成卡片。相邻 cue 至少留 0.35 秒进入间隔，同一触发词默认冷却 10 秒。

## 动效节奏

- 入场 0.25–0.45 秒，使用 outExpo/outBack；
- 稳定态至少 0.5 秒，让观众读完卡片；
- 退场 0.25–0.4 秒，沿入场方向反向退出；
- 数字先出现标签，再滚动到结论；步骤按 0.12–0.2 秒错峰；设备卡先画轮廓，再出现说明；
- 音效只服务主要落点：卡片 pop、转场 whoosh、数字 tick，避免每个字都响。

## 资产规则

UI 截图、手机录屏、Logo、图表和数字必须来自用户素材、项目资产或可追溯来源。cue 可以引用 `asset`，渲染前由 `validate_motion_cues.py` 检查 `public/` 中文件存在。没有真实资产时使用抽象示意卡，并在画面中标注“示意”。

## 验收

逐镜头检查人物脸和手势没有被覆盖，卡片文字没有溢出，字幕带保持空白，所有 cue 都在对应关键词前后出现，PIP 与 stage 的切换没有硬切或黑帧。结构达到参考片的 90% 只代表视觉语法和节奏相近；逐帧素材相似度取决于实际 UI/录屏/Logo 资产。
